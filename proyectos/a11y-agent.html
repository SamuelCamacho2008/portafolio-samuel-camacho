01 / PROYECTO DESTACADO — ACCESIBILIDAD WEB & IA

A11y Agent

Auditor autónomo y especialista en accesibilidad web bajo el estándar internacional WCAG 2.0 / 2.1 / 2.2 (niveles A, AA y AAA). Diseñado con la taxonomía y rigor estructural del modelo de referencia TAW (tawdis.net), pero potenciado con modelos de lenguaje para juicio semántico contextual, remediación de código guiada y asistencia en vivo.

WCAG 2.2 Compliant Python 3.11+ FastAPI Playwright (Chromium) axe-core 4.10 Claude / GPT-4o / Gemini Docker
01 / ESTRUCTURA TAW

4 Principios & Triaje Riguroso

Clasifica cada incidencia bajo los 4 principios W3C (Perceptible, Operable, Comprensible y Robusto), separando entre Problemas deterministas, Advertencias para revisión experta y No verificados.

02 / IA SEMÁNTICA

Juicio Contextual con LLM

Evalúa la calidad real de los textos alternativos de imágenes, el significado de enlaces aislados ("clic aquí", "leer más"), saltos en la jerarquía de encabezados y etiquetado de formularios.

03 / REMEDIACIÓN GUIADA

Solución Antes vs Después

No se limita a reportar el error; entrega el fragmento de código HTML/CSS corregido listo para copiar, junto con la técnica W3C aplicable y el esfuerzo estimado (bajo, medio, alto).

04 / ANTI-ALUCINACIÓN

Salvaguardas Epistemológicas

Todo hallazgo de IA está anclado a un nodo real del DOM vivo y se etiqueta estrictamente como Advertencia. Si no hay evidencia física en el DOM, se clasifica como No verificado.

05 / REPORTE MULTI-FORMATO

HTML, JSON y PDF Vectorial

Genera reportes interactivos navegables, salidas JSON estructuradas para pipelines de CI/CD y documentos PDF de alta fidelidad impresos mediante el motor Chromium de Playwright.

06 / CHAT EN VIVO

Asistente de Consulta

Permite al desarrollador conversar con el agente directamente: "¿Cómo soluciono el problema 2?" o "¿Por qué falla el contraste del botón?", guiando la remediación paso a paso.

Proyecto de Código Abierto

El código completo, la batería de 18 pruebas automatizadas, los fixtures de validación y la configuración Docker están disponibles en GitHub.
