Arquitectura e Innovación Técnica

SPAs Complejas & Rendering Híbrido

Manejo simultáneo de arquitecturas modernas: VTEX FastStore (Éxito), Next.js SPA con JSON embebido (Falabella) y VTEX IO (Jumbo). Sincronización inteligente sin bloqueos de red ni timeouts.

Actualización Continua con GitHub Actions

Un workflow automatizado en la nube ejecuta el scraper de Playwright a diario (cron job), detecta fluctuaciones de precios, actualiza el JSON estructurado y republica el portafolio en GitHub Pages sin intervención humana.

Normalización & Heurística de Datos

Parsing regex para extraer tamaño en pulgadas, tipo de panel (OLED, QNED, Mini LED, Crystal UHD) y resolución (4K, FHD), descartando automáticamente falsos positivos como proyectores o soportes de pared.
